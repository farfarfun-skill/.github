# .github

farfarfun-skill 组织的 Community Health Files 仓库。它承载组织主页展示的 profile README，本身不包含可安装的 Skill。

## Install

无需安装：这是 GitHub 特殊仓库，[`profile/README.md`](profile/README.md) 会自动渲染到 [组织主页](https://github.com/farfarfun-skill)。

## Usage

要新增或修改组织主页展示的内容，直接编辑 [`profile/README.md`](profile/README.md) 并提交。

新增或调整 Skill 时需要同步两处手工维护的清单：本仓库 `profile/README.md` 的「仓库总览」表，以及 [`skill-router`](https://github.com/farfarfun-skill/skill-router) 的路由表。两处都不会自动跟随各仓库变化。
